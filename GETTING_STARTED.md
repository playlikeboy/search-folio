Thank you for purchasing SearchFolio. You are minutes away from having the coolest portfolio on the internet.

## 📦 What's Included?
1. **Source Code**: The full Next.js project.
2. **Documentation**: Detailed guides on customization and deployment.

## ⚡ Quick Start

1. **Unzip** this folder.
2. Open your terminal and navigate to the folder:
   ```bash
   cd search-folio
   ```
3. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 How to Customize

All content is managed in two configuration files. You don't need to touch complex code!

1. **Edit Content**: Open `src/config/portfolio.ts`
   - Change your name, bio, social links, and projects here.
2. **Edit Theme**: Open `src/config/theme.ts`
   - Toggle "Show Search Stats", change colors, or update the logo.

## 🚀 How to Deploy

We recommend **Cloudflare Pages** (it's fast and free).

1. Push this code to a GitHub repository.
2. Go to Cloudflare Dashboard > Pages > Connect to Git.
3. Select your repository.
4. **Build Command**: `div` (leave default) or `npm run build`
5. **Output Directory**: `out`
6. Click **Save and Deploy**.

*Detailed deployment instructions are in `docs/DEPLOYMENT.md`.*
